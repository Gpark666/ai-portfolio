각 프로젝트에는 소개, 본인 기여, 주요 결과, 아키텍처, 코드와 노트북의 읽는 순서를 담았습니다. 골프 코칭 서비스와 이후 단독으로 진행한 모션 예측 연구는 별도 저장소로 구성했습니다.

## 대표 연구 결과

골프 모션 예측에서는 32프레임을 사용하는 Direct GRU와 8개 키프레임을 사용하는 Input-KF Attention-GRU를 비교했습니다. 논문 보고 MPJPE는 각각 88.549 mm와 88.381 mm로, 입력 프레임 수를 4분의 1로 줄인 조건에서 유사한 위치 오차를 보였습니다. 전체 MSE 최저 모델은 Direct GRU였으며, 키프레임 모델군의 MSE 최저 모델은 Transformer였습니다.

## 프로젝트 기록

개발 시기와 원본 파일 수정 시점은 각 프로젝트 문서와 노트북 대응표에 기록했습니다. 공개용 사본 정리일은 2026년 11월 24일입니다. 대규모 데이터셋·가중치·인증 파일은 저장소에서 제외했습니다.
